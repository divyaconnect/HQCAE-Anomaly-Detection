# HQCAE-Anomaly-Detection
Hybrid Quantum-Classical Autoencoder (HQCAE) for Anomaly Detection
Abstract
This research proposes a Hybrid Quantum-Classical Autoencoder (HQCAE) for anomaly representation and detection. The framework combines classical neural networks with parameterized quantum circuits and utilizes dual-space anomaly scoring based on reconstruction error and quantum entanglement entropy.

Features
Hybrid Quantum-Classical Architecture
4-Qubit Parameterized Quantum Circuit
Dual-Space Anomaly Detection
Von Neumann Entanglement Entropy
PennyLane + PyTorch Implementation
Results
ROC-AUC: 0.97
Improved anomaly detection capability
Reduced false negatives using quantum entropy information
